Architecture · Free-First

How the real pipeline works

This frontend speaks a documented REST API. Point it at a server running the open-source stack below and every stage becomes real. Nothing here is simulated.

Processing pipeline

1. Upload video → validated server-side (type, size, malware scan)
↓ FFmpeg
2. Extract audio (16kHz mono WAV) + preserve background track
↓ Whisper (open-source, openai/whisper or faster-whisper)
3. Speech-to-text with word-level timestamps + language detection
↓ NLLB-200 / Opus-MT / LibreTranslate (open-source)
4. Translate transcript segment-by-segment, preserve timestamps
↓ Piper / Coqui TTS / MMS-TTS (open-source)
5. Generate translated speech per segment (normal AI voices — no cloning claimed)
↓ FFmpeg
6. Time-stretch / sync dubbed segments; mix with original background audio at user volumes
↓ FFmpeg mux + burn/soft subs
7. Mux translated audio + original video + subtitles → final MP4 (original quality preserved)

Run your own free backend

# docker-compose.yml — free & open-source services: api: # FastAPI/Node job server + rate limiting worker: # Celery/RQ worker: FFmpeg + Whisper + NLLB + Piper redis: # job queue (long videos = background jobs) minio: # protected, user-scoped object storage # GPU recommended for Whisper large-v3 / NLLB-3.3B # CPU-only works but is slow for long videos
Set API_BASE in the frontend to your server. Temporary processing files are auto-deleted after job completion or failure.

Security & privacy

  • Secure file uploads with MIME + magic-byte validation, size limits, and server-side antivirus scanning.
  • User-specific projects in protected, private storage — videos are never exposed publicly.
  • API keys never ship to the browser; all model calls run server-side. Rate limiting per user/IP.
  • Temporary audio/transcript files auto-clean after processing. Try without registration; registered users get history & exports.
  • Future languages (Spanish, German, Italian, Portuguese, Turkish, Japanese, Korean, Russian, Hindi) are added by dropping in new Whisper/NLLB/TTS models — no UI change needed.
